# ESP32-C3-02 KiCad Design

A custom **ESP32-C3-02 Development Board** designed from scratch using **KiCad**. This repository contains the complete hardware design, including schematic, PCB layout, and supporting files for manufacturing and development.

---

## 📖 Project Overview

This project demonstrates the complete design of an ESP32-C3-02 based development board. The board is intended for embedded systems, IoT applications, and custom hardware development.

The design was created entirely in KiCad, following standard PCB design practices.

---

## ✨ Features

- ESP32-C3-02 Wi-Fi + Bluetooth MCU
- USB programming interface
- Power regulation circuit
- Reset and Boot buttons
- GPIO breakout
- Status LEDs
- Compact PCB layout
- Designed completely in KiCad

---

## 📂 Repository Contents

- Schematic (.kicad_sch)
- PCB Layout (.kicad_pcb)
- KiCad Project Files
- Symbol Libraries
- Footprint Libraries
- Manufacturing Files (Gerbers)
- Bill of Materials (BOM)

## 🛠 Software Used
